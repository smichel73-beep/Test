# Lokale KI Setup – Apple M5 / 24 GB RAM

Automatisiertes Installationsskript für eine lokale KI-Umgebung mit Ollama + Open WebUI,
optimiert für Apple Silicon (M5, 24 GB RAM).

## Dateien

| Datei | Zweck |
|-------|-------|
| `install_lokale_ki.sh` | Vollständiges Setup-Skript (einmalig ausführen) |
| `QUICKREF.md` | Schnellreferenz für den täglichen Betrieb |

## Installation

```zsh
chmod +x install_lokale_ki.sh
./install_lokale_ki.sh
```

Danach neues Terminal öffnen → `ki-start`

Siehe [QUICKREF.md](QUICKREF.md) für alle Aliase und Modelle.
